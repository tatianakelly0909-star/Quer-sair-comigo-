# 💌 Quer sair comigo?

Um projeto simples, interativo e divertido feito com HTML, CSS e JavaScript para fazer a famosa pergunta "Quer sair comigo?".

## 🚀 Como funciona?
O projeto exibe uma pergunta na tela com dois botões: **Sim** e **Não**. 
- Se a pessoa tentar clicar em "Não", o botão foge ou muda de lugar (dependendo da sua lógica).
- Quando a pessoa clica em "Sim", uma mensagem fofa de confirmação aparece na tela!

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript
